# growthCT — แอปเช็คการเติบโตฝ่ายวิญญาณ 9 ด้าน

> รองรับ 2 ภาษา: **ไทย / English** — สลับได้ทันทีด้วยปุ่มภาษา (🌐) บนแถบบน หรือหน้าลงทะเบียน
> Bilingual (Thai/English) — tap the language button in the top bar to switch anytime.

แอปง่าย ๆ สำหรับองค์กร/คริสตจักร ใช้ติดตามการเติบโตฝ่ายวิญญาณของสาวก
อ้างอิงจาก **"แบบประเมินสุขภาพฝ่ายวิญญาณของสาวก"** 9 ด้าน
โดยใช้สเกลการเติบโต **รู้ → กระทำ → แบ่งปัน** (Know → Do → Share)

แอปทำงานบนมือถือ ติดตั้งเป็นแอป (PWA) ได้ และ **ใช้งานออฟไลน์ได้เต็มรูปแบบ**
ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องสมัครบัญชี ข้อมูลเก็บอยู่ในเครื่องของผู้ใช้เอง

## ทำอะไรได้บ้าง (ตามที่ขอ)

| ความต้องการ | ในแอป |
|---|---|
| ลงทะเบียนผู้ใช้ | หน้า **ลงทะเบียน** กรอกชื่อ บทบาท วันรับเชื่อ และผู้ดูแล |
| เช็คส่วนตัวก่อน | หน้า **ประเมิน** ติ๊กระดับ รู้/กระทำ/แบ่งปัน ของแต่ละข้อพระคัมภีร์ |
| ให้ผู้เชื่อใหม่โหลดแล้วเช็คเอง | แชร์ลิงก์แอป → กด "เพิ่มลงหน้าจอโฮม" ใช้เป็นแอปได้เลย |
| ส่ง Report ให้ผู้ดูแล (มือถือ) | หน้า **ส่งรายงาน** → แชร์ผ่าน LINE/ข้อความ หรือคัดลอกลิงก์ |
| ผู้นำเห็นภาพรวม + รวมสถิติทั้งหมด | แท็บ **ทีม** วางลิงก์รายงานที่สมาชิกส่งมา → รวมเป็นสถิติทีม |
| ผู้ดูแลเพิ่มสมาชิกเอง + ประเมินให้ | แท็บ **ทีม** → "➕ เพิ่มสมาชิกใหม่" → แตะชื่อ → "ประเมินให้สมาชิกนี้" (ทำได้ในเครื่องเดียว) |
| ส่งลิงก์ให้สมาชิกกรอกเอง | หน้าสมาชิก → "🔗 ส่งลิงก์ให้ … กรอกเอง" → copy/แชร์ทาง LINE สมาชิกเปิดแล้วประเมินเอง เห็นแค่ของตัวเอง |
| เข้าถึงทีมงานรายบุคคล | แตะชื่อสมาชิกในแท็บทีม → ดูรายละเอียด 9 ด้าน + ประวัติการประเมินของคนนั้น |
| อ่านข้อพระคัมภีร์ | แตะที่ข้ออ้างอิงในหน้าประเมิน → ป๊อบอัพแสดงเนื้อหา (ฉบับ 1971) |

## 9 ด้านที่ประเมิน

1. 🙌 นมัสการร่วมกัน
2. 🙏 อธิษฐาน และ อดอาหาร
3. 🍚 อุทิศเวลา และ ถวายทรัพย์
4. 🤝 ดำเนินชีวิตอย่างมีชัยชนะ
5. ❤️ รักพระเจ้า และ รักผู้อื่น
6. 🍷 พิธีมหาสนิท และ บัพติศมา
7. 📖 ศึกษาและเชื่อฟังพระวจนะ
8. 🌱 สร้างสาวกที่สร้างสาวก
9. 🧭 ยอมจำนนและรายงานชีวิต

แต่ละด้านมีข้อพระคัมภีร์อ้างอิง และให้ติ๊กว่าไปถึงระดับใด (รู้ / กระทำ / แบ่งปัน)
ระบบจะคิดคะแนนรวมและเปอร์เซ็นต์ของแต่ละด้านให้อัตโนมัติ

## วิธีใช้งานทั่วไป

### สำหรับผู้เชื่อใหม่ / สาวก
1. เปิดลิงก์แอป → ลงทะเบียน (เลือกบทบาท "ผู้เชื่อใหม่ / สาวก")
2. กด **เริ่มประเมิน** ติ๊กตามความจริงในชีวิต
3. ดูผลภาพรวมและรายด้าน
4. กด **ส่งรายงานให้ผู้ดูแล** → แชร์ผ่าน LINE หรือคัดลอกลิงก์ส่งให้พี่เลี้ยง
5. ทำซ้ำเป็นช่วง ๆ (เช่น ทุกเดือน) ระบบเก็บประวัติและเทียบความก้าวหน้าให้

### สำหรับผู้ดูแล / ผู้นำ
1. ลงทะเบียน (เลือกบทบาท "ผู้ดูแล / ผู้นำกลุ่ม")
2. ไปแท็บ **ทีม** → "➕ เพิ่มสมาชิกใหม่" ใส่ชื่อ
3. แตะชื่อสมาชิก เลือกได้ 2 ทาง:
   - **ประเมินให้เลย** (ผู้นำกรอกแทนในเครื่องตัวเอง) หรือ
   - **🔗 ส่งลิงก์ให้กรอกเอง** → copy/แชร์ทาง LINE ให้สมาชิก
4. เมื่อสมาชิกประเมินเสร็จแล้วกด "ส่งให้ผู้นำ" → คุณเปิดลิงก์ที่เขาส่งกลับมา → ข้อมูลเข้าภาพรวมทีม
5. แท็บทีมแสดง **ค่าเฉลี่ยการเติบโตของทีม**, **ด้านที่อ่อนที่สุด** และรายชื่อสมาชิกทุกคนพร้อม %

### ลิงก์เชิญ & ความเป็นส่วนตัวของสมาชิก
- ลิงก์เชิญมีรูปแบบ `#invite?n=<ชื่อ>&by=<ผู้นำ>` — สมาชิกเปิดแล้วแอปตั้งค่าเป็นของเขาอัตโนมัติ
- ข้อมูลของสมาชิกเก็บใน**เครื่องของเขาเอง** เห็นเฉพาะของตัวเอง ไม่เห็นของคนอื่น
- การส่งผลกลับให้ผู้นำเป็นการแชร์ลิงก์ (สมาชิกกดเอง 1 ครั้ง) — ไม่มีเซิร์ฟเวอร์กลาง

> **หมายเหตุ:** เนื่องจากไม่มีเซิร์ฟเวอร์ ข้อมูลจึงไม่ sync อัตโนมัติ — สมาชิกต้องกด "ส่งให้ผู้นำ" เมื่อต้องการอัปเดต หากต้องการให้ข้อมูลขึ้นที่ผู้นำเองอัตโนมัติแบบเรียลไทม์ สามารถต่อยอดเพิ่มฐานข้อมูลคลาวด์ (Supabase/Firebase) ได้ภายหลัง

> การส่งรายงานทำผ่าน "ลิงก์ที่ฝังข้อมูลไว้" ผู้ดูแลเปิดลิงก์แล้วข้อมูลจะเข้าแอปทันที — ไม่ต้องใช้ฐานข้อมูลกลาง เหมาะกับการเริ่มต้นใช้ในกลุ่มเล็ก

## การนำไปใช้ / โฮสต์ (Deploy)

แอปเป็นไฟล์สแตติกล้วน เปิดได้หลายวิธี:

**ทดสอบในเครื่อง**
```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```

**โฮสต์ฟรีด้วย GitHub Pages**
1. Push โค้ดขึ้น GitHub
2. ไปที่ Settings → Pages → เลือก branch (เช่น `main`) โฟลเดอร์ `/ (root)`
3. ได้ลิงก์ `https://<user>.github.io/<repo>/` → แชร์ให้ทุกคนใช้ได้ทันที

ใช้ได้กับ Netlify, Vercel, Cloudflare Pages หรือเว็บโฮสต์ทั่วไปได้เช่นกัน (อัปโหลดทุกไฟล์)

---

## โครงสร้างไฟล์
```
index.html             หน้าหลัก (โหลดสคริปต์)
styles.css             สไตล์ UI มือถือ
data.js                เนื้อหา 9 ด้าน + ข้อพระคัมภีร์ (แก้ไขได้)
app.js                 ตรรกะแอป: เก็บข้อมูล, คิดคะแนน, ส่ง/รับรายงาน
manifest.webmanifest   ตั้งค่า PWA
sw.js                  service worker (ออฟไลน์)
icons/                 ไอคอนแอป
```

แก้ข้อความ/ข้อพระคัมภีร์ของแต่ละด้านได้ที่ `data.js`

## ข้อพระคัมภีร์
แต่ละข้ออ้างอิงในหน้าประเมินแตะได้ จะแสดงเนื้อหาพระคัมภีร์ **ฉบับสมาคมพระคริสตธรรมไทย 1971**
ในป๊อบอัพ (ฝังไว้ในแอป จึงเปิดได้ทันทีและใช้งานออฟไลน์)
เนื้อหาพระคัมภีร์เฉพาะข้อที่ใช้ในแบบประเมิน เก็บอยู่ในไฟล์ `bible.js`
แหล่งข้อมูลข้อความ: ชุดข้อมูล [dearteno/ThaiBibleXML](https://github.com/dearteno/ThaiBibleXML) (ตาราง `tbs_verses` = ฉบับ 1971)
ลิขสิทธิ์เนื้อหาพระคัมภีร์เป็นของสมาคมพระคริสตธรรมไทย

## ความเป็นส่วนตัว
ข้อมูลการประเมินทั้งหมดเก็บใน `localStorage` ของอุปกรณ์ผู้ใช้เท่านั้น
ไม่มีการส่งข้อมูลออกไปที่เซิร์ฟเวอร์ใด ๆ การส่งรายงานเป็นการแชร์ลิงก์ที่ผู้ใช้กดเองทั้งหมด

## แนวทางพัฒนาต่อ (ถ้าต้องการ)
หากองค์กรโตขึ้นและอยากมีฐานข้อมูลกลาง / ล็อกอินจริง / แดชบอร์ดผู้นำแบบเรียลไทม์
สามารถต่อยอดเพิ่ม backend (เช่น Firebase หรือ Supabase) ได้ภายหลัง โดยคงโครงหน้าจอเดิมไว้
