# เพิ่มบท และเพิ่มเล่ม — ทีละบท ทีละเล่ม

แผนคือเริ่มที่ **เอเฟซัส** ให้เสร็จก่อน แล้วค่อยเพิ่มเล่มถัดไปทีละเล่ม
โค้ดถูกจัดให้รองรับแผนนี้แล้ว: การเปิดบทใหม่คือ **การเพิ่มไฟล์เนื้อหาอย่างเดียว**
ไม่ต้องแก้ route ไม่ต้องแก้สคริปต์ตรวจสอบ ไม่ต้องแก้หน้าเล่ม

---

## เพิ่มบทถัดไปของเล่มที่เปิดอยู่แล้ว (เช่น เอเฟซัส 2)

วางไฟล์เดียว:

```
content/books/ephesians/th/chapter-02.json
```

เท่านั้น แล้ว

* `/th/books/ephesians/2` ถูกสร้างเป็นหน้า static อัตโนมัติ
* หน้าเล่มเอเฟซัสเปลี่ยนบทที่ 2 จาก "กำลังเตรียม" เป็นกดเข้าไปอ่านได้
* แก้วของเอเฟซัสในห้องสมุดขยับตามเมื่อผู้อ่านอ่านจบ (2 จาก 6 บท)

ตรวจก่อนส่ง:

```bash
pnpm validate:content   # ตรวจ schema + คำใน 3 Words Check ว่ามีอยู่จริงในเนื้อหา
pnpm build
```

---

## เพิ่มเล่มใหม่ (เช่น ยอห์น)

สองขั้นตอน:

**1. วางไฟล์เนื้อหา**

```
content/books/john/th/chapter-01.json
```

ชื่อโฟลเดอร์ต้องตรงกับ `id` ใน `src/lib/books/canon.ts` (ของยอห์นคือ `john`)

**2. เพิ่ม id ลงใน `BOOKS_WITH_LESSONS` ใน `src/lib/books/canon.ts`**

```ts
const BOOKS_WITH_LESSONS = new Set<string>(["ephesians", "john"]);
```

ถ้าลืมขั้นตอนใดขั้นตอนหนึ่ง `pnpm validate:content` จะ **ไม่ผ่าน** และบอกตรง ๆ ว่าขาดอะไร

```
✗ content exists for "john", but canon.ts does not list it in BOOKS_WITH_LESSONS
✗ canon.ts marks "john" as ready, but content/books/john/th has no chapters
```

ที่ต้องมีสองขั้นตอน เพราะห้องสมุดกับแดชบอร์ดเป็น client component
จึงอ่านไฟล์ในเครื่องไม่ได้ — `canon.ts` เลยเป็นตัวประกาศ และตัวตรวจสอบคอยกันไม่ให้สองอย่างนี้เพี้ยนจากกัน

---

## สิ่งที่ระบบจะไม่ยอมให้เกิดขึ้น

* ห้องสมุดบอกว่าเล่มไหน "พร้อมอ่าน" ทั้งที่ยังไม่มีเนื้อหา
* มีเนื้อหาวางอยู่แต่ไม่มีใครเห็น เพราะลืมประกาศใน canon
* บทที่ยังไม่เปิด ถูกลิงก์ไปหน้าที่ไม่มีอยู่จริง (route จะ 404 อย่างตั้งใจ ไม่ใช่พัง)
* เนื้อหาที่ยังเป็น `draft` ถูกเข้าใจผิดว่าพร้อมทดสอบกับผู้อ่านจริง —
  `pnpm validate:content` จะเตือนทุกครั้ง

---

## ความคืบหน้าของผู้อ่านเมื่อเพิ่มบทใหม่

ความคืบหน้าเก็บเป็น "บทที่อ่านจบ" ไม่ใช่เปอร์เซ็นต์
การเพิ่มบทใหม่จึงไม่ทำให้ข้อมูลเดิมของใครเสีย — เอเฟซัสมี 6 บทเสมอตาม canon
ผู้ที่อ่านบทที่ 1 จบแล้วจะเห็น 1/6 เท่าเดิม และเห็นบทที่ 2 เปิดเพิ่มขึ้นมา
