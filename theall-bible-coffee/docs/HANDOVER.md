## 2 · เติมตัวบทพระคัมภีร์ — จุดเดียว ไม่ต้องแก้โค้ด

นี่คือสิ่งที่ยังขาดอยู่จริง ๆ และระบบรออยู่แล้ว

ในไฟล์ `content/books/<book>/th/chapter-NN.json` เปลี่ยนบล็อก `scripture` จาก

```json
"scripture": {
  "reference": "ปฐมกาล 1",
  "translationId": null,
  "text": null,
  "rightsStatus": "reference-only",
  "attribution": null, "license": null, "copyrightNotice": null
}
```

เป็น

```json
"scripture": {
  "reference": "ปฐมกาล 1",
  "translationId": "<รหัสฉบับแปล>",
  "text": "1 …\n2 …",
  "rightsStatus": "licensed",
  "attribution": "<ชื่อฉบับแปลเต็ม · เจ้าของลิขสิทธิ์>",
  "license": "<ชื่อสัญญาอนุญาต>",
  "copyrightNotice": "<ข้อความลิขสิทธิ์ตามที่เจ้าของกำหนด>"
}
```

แล้วหน้าจอจะแสดงตัวบทพร้อมเครดิตใต้ข้อความอัตโนมัติ

**schema บังคับไว้ทั้งสองทาง**

- `reference-only` **ห้าม**มี `text`
- `licensed` **ต้อง**มี `text` + `translationId` + `attribution` + `license` ครบ ไม่งั้น `pnpm validate:content` ไม่ผ่าน

จึงเป็นไปไม่ได้ที่ตัวบทจะขึ้นหน้าจอโดยไม่มีเครดิต — **นี่คือกลไกที่กันความผิดพลาดเรื่องลิขสิทธิ์**
ถ้าฉบับแปลเป็น CC BY-SA การให้เครดิตเป็นเงื่อนไขของสัญญาอนุญาต ไม่ใช่ทางเลือก

## 3 · เพิ่มบทใหม่ — วางไฟล์อย่างเดียว

`content/books/genesis/th/chapter-04.json` → route `/th/books/genesis/4` เกิดขึ้นเอง
แผนที่เล่มเปิดบทนั้นเอง แก้วขยับเอง

เพิ่ม**เล่มใหม่** = วางไฟล์ + เพิ่ม id ใน `BOOKS_WITH_LESSONS` (`src/lib/books/canon.ts`)
ลืมข้อใดข้อหนึ่ง validator ฟ้องทันที

รายละเอียด: `docs/ADDING_A_CHAPTER.md`

## 5 · สถานะเนื้อหาตามจริง

| บท | สถานะ | ยังขาด |
|---|---|---|
| ปฐมกาล 1 | `draft` | ตัวบทพระคัมภีร์ · 2 sources ยัง `unverified` |
| ปฐมกาล 2–3 | `draft` | เรื่องจริง · งานวิจัย · ตัวบทพระคัมภีร์ |
| เอเฟซัส 1 | `draft` | เรื่องจริง (ตอนนี้เป็นสถานการณ์สมมติ) · 3 sources ยัง `unverified` |

ปฐมกาล 1 มีเรื่องจริงแล้ว — Ian Campbell · โรงพยาบาล Chikankata แซมเบีย · แนวทาง SALT
พร้อมกล่อง "เรื่องจริง · ไม่แต่งรายละเอียด" และประโยคที่บอกตรง ๆ ว่า
**เรื่องนี้ไม่ได้ถูกใช้พิสูจน์ตัวบท** ทั้งสองอย่างอยู่บนหน้าจอ ไม่ใช่แค่ในเอกสาร

ทุกบทที่เว้นช่องไว้ **แสดงคำอธิบายบนหน้าจอ** ว่าเว้นทำไม — ตั้งใจให้คนรีวิวเห็น ไม่ใช่ซ่อน

เรื่องจริงที่ต้องหา — ปฐมกาล 2: คนที่รู้สึกผิดเวลาได้พัก ·
ปฐมกาล 3: คนที่ซ่อนบางอย่างไว้เพราะกลัวถูกเห็น

ขั้นตอนขอความยินยอมอยู่ใน `docs/RESEARCH_PROTOCOL.md` ข้อ 4
