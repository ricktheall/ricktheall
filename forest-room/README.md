Forest Room

ระบบหน้าร้านสำหรับคาเฟ่ พื้นที่เช่า และ co-working ในแอปเดียว

สิ่งที่ทำได้

ขายหน้าร้าน แตะเมนูลงบิล เลือกช่องทาง ทานที่ร้าน กลับบ้าน Grab หรือ LINE MAN ผูกสมาชิกเพื่อรับส่วนลดและแต้ม
ชำระเงิน เงินสดพร้อมคำนวณเงินทอน PromptPay QR พร้อมยอดเงิน บัตร หรือโอน
จอครัว ออเดอร์เข้าทันทีหลังชำระเงิน เลื่อนสถานะ ใหม่ กำลังทำ พร้อมเสิร์ฟ
พื้นที่เช่า ตารางเวลารายวันของทุกห้อง จองพร้อมเช็คเวลาชน คำนวณราคาตามชั่วโมง เช็คอิน รับชำระ
สมาชิก co-working แพ็กเกจรายเดือนหรือแบบนับครั้ง เช็คอิน ต่ออายุ เตือนใกล้หมดอายุ แต้มสะสม
สต็อก ตัดวัตถุดิบตามสูตรทุกครั้งที่ขาย เตือนเมื่อต่ำกว่าจุดสั่งซื้อ
รายงาน รายได้แยก อาหารและเครื่องดื่ม พื้นที่เช่า co-working เมนูขายดี วิธีชำระ ช่องทางขาย

ไฟล์

app.html คือหน้าแอปที่เผยแพร่เป็น Claude Artifact ข้อมูลซิงก์ทุกเครื่องผ่านฐานข้อมูลของ artifact
index.html คือเวอร์ชันเปิดตรงจาก GitHub Pages ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนั้น
build.mjs สร้าง index.html จาก app.html ใช้คำสั่ง node forest-room/build.mjs หลังแก้ app.html ทุกครั้ง

ข้อจำกัดตอนนี้

QR PromptPay ยังต้องให้พนักงานตรวจยอดเข้าแล้วกดปิดบิลเอง การปิดบิลอัตโนมัติต้องต่อ API ของธนาคาร
Grab และ LINE MAN ยังเป็นการบันทึกช่องทางขาย ยังไม่ได้ดึงออเดอร์จากแอปเดลิเวอรี่อัตโนมัติ
ยังไม่มีระบบล็อกอินแยกสิทธิ์พนักงาน และยังไม่พิมพ์ใบเสร็จผ่านเครื่องพิมพ์
